# Brand guidelines for this test site

`technova-brand-guidelines.html` is the source and `TechNova-Brand-Guidelines-v3.pdf` the
rendered copy of the TechNova Solutions brand and content guidelines. The PDF is the file to
upload as this project's knowledge base in the Superflow portal (project settings, Knowledge
Base section) when testing per-project brand guidelines.

The buggy home page variant breaks these rules on purpose: "Docs" nav label (rule 7),
`javascript:void(0)`, `#` and empty hrefs (rule 8), "Learn More" alone (rule 9), eight nav
links (rule 10), emoji feature icons (rule 16), no read time on blog cards (rule 18),
credentials and PII in the code sample (rules 20 and 21), profanity in testimonials (rule 4),
a testimonial attributed to an email address (rule 23), and a 2024 copyright year (rule 25).

The sibling site raghul-velt/velt-test-double (Meridian Outfitters) carries its own, different
document, so a Workspace Agent run can be checked for using the right project's guidelines.
