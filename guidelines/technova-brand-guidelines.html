TechNova Solutions: Brand and Content Guidelines

Version 3.0 · Applies to technova-solutions web properties · Owner: Developer Marketing · Scope: the TechNova developer platform site only

1. Brand name and voice

  1. Always write the company name as "TechNova" as one word with a capital T and a capital N. Never write "Technova", "Tech Nova", or "TECHNOVA".
  2. Always use the full name "TechNova Solutions" in the page title and in the footer copyright line.
  3. Always refer to customers as "teams" or "engineering teams". Never call them "users" in marketing copy.
  4. Never publish profanity, censored profanity, or asterisked expletives anywhere on the site, including inside customer testimonials. Remove or replace the quotation.
  5. Never use exclamation marks in headings, buttons, or body copy.
  6. Always use United States English spelling.

2. Navigation and links

  1. Always label the documentation link "Documentation". Never abbreviate it to "Docs" in navigation or footer links.
  2. Never publish a link whose destination is "javascript:void(0)", a bare "#", or an empty href. Every link must resolve to a real page.
  3. Always write call to action labels as a verb phrase of three or more words. Never use "Learn More" on its own; write "Learn more about the platform" or "Read the platform overview".
  4. Always keep the sticky top navigation to at most six links plus one call to action button.
  5. Always keep a "Pricing" link in the main navigation that goes to the /pricing page.
  6. Always open links to external domains in a new tab with rel="noopener noreferrer".

3. Color and typography

  1. Always use the primary purple #6C5CE7 for primary buttons and the logo mark. Never introduce a second accent color for buttons.
  2. Always use the secondary teal #00CEC9 only for highlights and decorative gradients. Never set text in teal.
  3. Always set headings and body copy in Geist Sans and code samples in Geist Mono.
  4. Never use emoji as feature icons, section icons, or blog thumbnails. Use the TechNova line icon set.
  5. Always use an 8 pixel corner radius on primary and secondary buttons.

4. Product and content

  1. Always show a read time formatted "N min read" on every blog card and every blog post.
  2. Always show a "Last updated" date on every documentation page and feature page.
  3. Never publish credentials, API keys, connection strings, private keys, internal IP addresses, or staging hostnames on any public page, including inside code samples and comments.
  4. Never publish personal data of employees or customers: dates of birth, personal email addresses, telephone numbers, government identifiers, or payment card numbers.
  5. Always write "CI/CD" with a forward slash. Never write "CICD" or "CI-CD".
  6. Always attribute every customer testimonial to a full name, a role, and a company. Never attribute a testimonial to an email address.
  7. Always describe pricing in "per month" terms with the currency symbol, for example "$3,000 per month". Never abbreviate to "/month" or "/mo".

5. Footer and legal

  1. Always show the footer copyright line as "© 2026 TechNova Solutions. All rights reserved." Never show an earlier year.
  2. Always include exactly one "Status" link in the footer that resolves to an https status page.
  3. Always list the footer columns in the order Product, Resources, Company, Contact.
  4. Never repeat the same destination twice within one footer column.

Questions about these guidelines go to brand@technova-solutions.example. This document supersedes version 2.4 and applies to the TechNova site only; it does not apply to other properties in the workspace.
